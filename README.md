# Spotify Visualizer

A Chrome extension that displays Spotify's "Now Playing" information in a beautiful Gaf-branded popup UI with an artist photo wall feature.

## Quick Start

See the [extension README](extension/README.md) for complete setup and installation instructions.

## Features

- **Spotify OAuth Authentication** with PKCE
- **Now Playing Display** with track info and progress
- **Artist Photo Wall** - 3x3 grid of artist images
- **Gaf Branding** with custom styling
- **Auto-refresh** every 5 seconds

## Installation

1. Set up a Spotify Developer App
2. Configure your Client ID in the extension files
3. Load the unpacked extension from the `/extension` folder
4. Connect to Spotify and enjoy!

For detailed instructions, see [extension/README.md](extension/README.md).
